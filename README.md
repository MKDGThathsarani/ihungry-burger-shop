# 🍔 iHungry Burger Shop Management System

A JavaFX-based desktop application for managing burger shop orders.
Developed as part of the iCET Certified Developer coursework.

## 🛠️ Tech Stack
- **Language:** Java 17
- **UI Framework:** JavaFX + FXML (Scene Builder)
- **Styling:** CSS
- **Database:** MySQL (JDBC)
- **Build Tool:** Maven
- **Pattern:** MVC

## ✨ Features
- Place Order (auto Order ID / Customer ID generation)
- Search Order by Order ID
- Search Customer with order history
- View Orders by status (Delivered / Processing / Canceled)
- Best Customer ranking (total purchases)
- Update Order (quantity/status — PREPARING only)

## 🚀 How to Run
1. Clone: `git clone <repo-url>`
2. Create MySQL DB: import `ihungry_db.sql`
3. Update DB credentials in `DBConnection.java`
4. Run: `mvn clean javafx:run`
